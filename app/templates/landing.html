How It Works

  1. 1
    Easy Auth intercepts the request

    Azure App Service Easy Auth checks for a valid Entra ID token before the request reaches your app.

  2. 2
    Claims are injected as a header

    The X-MS-CLIENT-PRINCIPAL header carries a base64-encoded JSON payload with all user claims, including roles.

  3. 3
    Flask reads and enforces roles

    A simple decorator checks the roles claim and either grants access or returns a friendly 403 — no token validation code needed.
